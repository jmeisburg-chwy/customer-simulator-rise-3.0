# Customer Simulator Production Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the Customer Simulator System Tools branch from reviewable pilot code to a repeatable production candidate with stack-owned AWS resources, deploy automation, and smoke-test evidence.

**Architecture:** Keep the existing single-file Lambda and Rise HTML runtime intact. Make AWS resource ownership explicit in `template.yaml`, keep scenario JSON as external S3 seed assets generated by repo scripts, and add small shell/Node automation for deploy and smoke checks rather than adding an application framework.

**Tech Stack:** Node.js built-ins, bash, AWS CLI, CloudFormation, Lambda Node.js runtime, API Gateway HTTP API, S3 scenario library, DynamoDB coaching table.

---

## File Structure

- Modify `template.yaml`: define stack-owned S3 and DynamoDB resources, wire Lambda environment variables from those resources, tighten IAM, and expose production-useful outputs.
- Modify `tests/behavior-framework.test.js`: add no-AWS regression tests that assert the CloudFormation template owns the expected resources and does not point production defaults at shared buckets/tables.
- Modify `scripts/package-lambda.sh`: keep Lambda packaging deterministic and make artifact paths machine-readable for deploy automation.
- Modify `scripts/prepare-stack-assets.js`: keep generated scenario seed assets consistent with the S3 runtime contract and fail fast when scenario ids or paths drift.
- Create `scripts/deploy-test-stack.sh`: package artifacts, upload Lambda/scenario assets, deploy or update a named test stack, and print stack outputs without exposing secrets.
- Create `scripts/smoke-test-api.js`: run lightweight API checks against a deployed `ApiUrl`.
- Modify `README.md`: replace manual-only production notes with the new test-stack and smoke-test workflow.

### Task 4: Add Safe Test-Stack Deploy Automation

**Files:**
- Create: `scripts/deploy-test-stack.sh`
- Modify: `README.md`

- [ ] **Step 1: Create a deploy script with explicit required inputs**

```bash
#!/usr/bin/env bash
set -euo pipefail

STACK_NAME="${STACK_NAME:-customer-simulator-system-tools-test}"
REGION="${AWS_REGION:-us-east-2}"
DEPLOY_BUCKET="${DEPLOY_BUCKET:-}"
OPENAI_API_KEY="${OPENAI_API_KEY:-}"

if [[ -z "$DEPLOY_BUCKET" ]]; then
  echo "DEPLOY_BUCKET is required." >&2
  exit 1
fi

if [[ -z "$OPENAI_API_KEY" ]]; then
  echo "OPENAI_API_KEY is required." >&2
  exit 1
fi

REPO_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
cd "$REPO_ROOT"

node tests/behavior-framework.test.js
node tests/chat-ui-layout.test.js
bash scripts/package-lambda.sh
node scripts/prepare-stack-assets.js

aws s3 cp dist/customer-simulator-lambda.zip "s3://${DEPLOY_BUCKET}/customer-simulator-lambda.zip" --region "$REGION"

aws cloudformation deploy \
  --stack-name "$STACK_NAME" \
  --template-file template.yaml \
  --capabilities CAPABILITY_NAMED_IAM \
  --parameter-overrides OpenAIApiKey="$OPENAI_API_KEY" \
  --region "$REGION"

SCENARIO_BUCKET="$(aws cloudformation describe-stacks \
  --stack-name "$STACK_NAME" \
  --region "$REGION" \
  --query "Stacks[0].Outputs[?OutputKey=='ScenarioLibraryBucketName'].OutputValue" \
  --output text)"

aws s3 sync dist/scenario-library "s3://${SCENARIO_BUCKET}/" --delete --region "$REGION"

aws cloudformation describe-stacks \
  --stack-name "$STACK_NAME" \
  --region "$REGION" \
  --query "Stacks[0].Outputs" \
  --output table
```

### Task 5: Add API Smoke Tests

**Files:**
- Create: `scripts/smoke-test-api.js`
- Modify: `README.md`

- [ ] **Step 1: Create the smoke test script**

```js
#!/usr/bin/env node

const apiUrl = String(process.env.API_URL || process.argv[2] || "").replace(/\/$/, "");

if (!apiUrl) {
  console.error("Usage: API_URL=https://... node scripts/smoke-test-api.js");
  process.exit(1);
}

async function getJson(path) {
  const response = await fetch(`${apiUrl}${path}`);
  const text = await response.text();
  if (!response.ok) {
    throw new Error(`${path} returned HTTP ${response.status}: ${text.slice(0, 500)}`);
  }
  return JSON.parse(text);
}

(async () => {
  const scenarios = await getJson("/scenarios");
  if (!Array.isArray(scenarios.scenarios) || scenarios.scenarios.length === 0) {
    throw new Error("/scenarios did not return a non-empty scenarios array");
  }

  const chatScenario = await getJson("/scenario?scenarioId=late_delivery_20_partial_refund_chat");
  if (chatScenario.id !== "late_delivery_20_partial_refund_chat") {
    throw new Error(`/scenario returned unexpected id ${chatScenario.id}`);
  }

  console.log("ok - /scenarios returned scenario metadata");
  console.log("ok - /scenario returned late_delivery_20_partial_refund_chat");
})().catch((error) => {
  console.error(error);
  process.exit(1);
});
```
